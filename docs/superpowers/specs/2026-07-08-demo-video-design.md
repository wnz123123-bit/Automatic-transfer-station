## 目标

制作约 75 秒的产品 demo 视频，展示：
1. 平台已实现二维材料转移的自动化控制（九轴运动 / 安全体系 / 控温 / 相机测量 / 双语界面）；
2. 正在发展 LLM 驱动的 AI 辅助自动转移（概念演示）。

风格对标 `E:\Measurix_Demo\Measurix_demo_1min.mp4`：深色标题卡 → 软件实录 + 底部中文字幕条 → LLM 模拟对话概念段 → 深色总结卡。

## 关键决策（已与用户确认）

- **素材**：纯 GUI 预览模式录屏（不连硬件、不点「打开运动控制/复位」）。
- **LLM 段**：模拟对话概念演示（同 Measurix），非真实 agent 录屏。
- **语言**：中文字幕 + 中文界面。
- **执行**：全自动化——脚本驱动 GUI 操作 + ffmpeg 录屏 + 程序化剪辑合成，用户只审片。
- **图片素材**：可上网检索二维材料光学显微照片（MoS₂/石墨烯薄片）。仅内部演示，无版权约束。

## 视频参数

- 1920×1080，30 fps，H.264 MP4，总时长约 75 s。
- 字幕条样式仿 Measurix：底部半透明黑条、白字、微软雅黑。
- 卡片段背景深藏青（约 #0d1b2a 系），标题白字、副标题浅蓝。

## 制作管线（方案 A）

1. **卡片段（1/7/8）**：Python + PIL（微软雅黑）逐帧渲染 PNG 序列 → ffmpeg 编码为段视频。第 7 段做打字机动画与图片渐显。
2. **GUI 实录段（2–6）**：
   - 以 `py -3.13 run_transfer_station.py` 启动（预览模式，**保留手柄支持**：XInput 无手柄连接时仍能加载并显示手柄面板，「?」帮助按钮可用，第 4 段依赖它；手柄未连接只影响摇杆输入，不影响帮助图）。
   - 窗口移动到固定位置/尺寸；录制前截图校验界面就位，不符则中止。
   - Windows API（SetCursorPos/mouse_event 或等价）真实移动光标并点击，观众可见光标；点击序列脚本化、坐标预校准。
   - ffmpeg gdigrab 录屏（全屏或窗口区域裁切）。
3. **字幕**：每段生成 ASS 字幕（样式统一），ffmpeg 烧录。
4. **合成**：ffmpeg concat + 段间 0.3–0.5 s 交叉淡化，输出 `demo/transfer_station_demo.mp4`。

## 安全红线

- 自动化脚本**绝不**点击「打开运动控制」「复位」按钮；点击序列的坐标远离该按钮区域。
- 预览模式下运动命令本就被程序忽略（双保险）。
- 录制前截图校验窗口位置；校验失败立即中止，不盲点。
- 录制期间提示用户勿动鼠标键盘。

## 图片素材

- 上网检索 1–3 张二维材料光学显微照片（MoS₂ / 石墨烯薄片，衬度清晰者），存 `demo/assets/`。
- 用途：第 7 段 LLM 对话内嵌的"视觉反馈"示意图。
- 第 5 段相机窗口的取舍规则（明确）：实施时先无相机试开相机窗口——若界面无醒目报错（仅空预览+控件），照常入镜；若有醒目报错/弹窗，则第 5 段只拍温度面板，相机功能用一张检索的显微薄片图 + 字幕带过。
- 仅内部演示使用，无版权约束（用户确认）。
