## 通用说明

- 控制卡速度参数 `speed` 当前按 `pulse/ms` 理解。
- 点位运动使用控制卡规划位置，单位为 `pulse`。
- 限位状态来自 `GA_GetSts`，外部输入来自 `GA_GetExtDiBit`。
- 真实坐标和控制卡规划位置的对应关系以本文件中每个轴的坐标约定为准。
- 后续测试限位时，未确认映射前不要只相信原程序映射；需要同时读取所有可用限位输入。
- 后续测试限位时，只允许超过标称行程 `2 mm` 即停止，不继续硬推。

| 方向 | 控制卡状态位 | 名称 | 外部输入 | 触发状态 |

轴 5 属于其他平移轴，按厂家信息：

| 项目 | 数值 |
| --- | --- |
| 驱动器细分 | `25000 pulse/rev` |
| 机械整步位移 | `2.5 um/full-step` |
| 默认电机整步数 | `200 full-step/rev` |
| 每转位移 | `500 um = 0.5 mm` |
| 距离换算 | `50000 pulse/mm` |
| 单脉冲位移 | `0.02 um/pulse` |

常用换算：

```text
+pulse = 向左
-pulse = 向右

1 mm = 50000 pulse
1 um = 50 pulse
1 pulse = 0.02 um
```
